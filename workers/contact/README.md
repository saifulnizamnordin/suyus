# suyus-contact

A Cloudflare Worker that reveals a portfolio's email address only to visitors who pass a **Cloudflare Turnstile** check.

- Portfolio files hold `emailEncrypted` (RSA-OAEP 2048 / SHA-256), encrypted with the public key in [`src/contact/public-key.json`](../../src/contact/public-key.json). Nothing readable is in the repo or the built site.
- The site shows an **Email** button. Clicking it opens a Turnstile challenge, and the resulting single-use token is sent here with the ciphertext.
- This Worker verifies the token with Cloudflare (`siteverify`, including hostname), then decrypts with the private key and returns the address.

```
POST https://contact.suy.us/reveal
{ "token": "<turnstile token>", "ciphertext": "v1.…" }   →   { "email": "…" }
```

Requests from other origins, without a valid token, or with tampered ciphertext are rejected.

## One-time setup

### 1. Create the Turnstile widget

Cloudflare dashboard → **Turnstile** → **Add widget**:

- **Hostnames:** `suy.us` (add `localhost` too if you want to test locally)
- **Widget mode:** Managed

Copy the **Site key** and the **Secret key**.

### 2. Deploy the Worker

From this folder:

```sh
cd workers/contact
npx wrangler login
npx wrangler secret put TURNSTILE_SECRET            # paste the Turnstile secret key
npx wrangler secret put EMAIL_PRIVATE_KEY < .secrets/email-private-key.json
npx wrangler deploy
```

`wrangler.toml` serves it at **`contact.suy.us`** as a Workers custom domain. The `suy.us` zone must be in the same Cloudflare account, and Wrangler creates the DNS record.

### 3. Turn the button on

Put the **Site key** in [`src/contact.ts`](../../src/contact.ts):

```ts
turnstileSiteKey: import.meta.env.PUBLIC_TURNSTILE_SITE_KEY ?? "0x4AAAA…",
```

Commit and push. Until a site key is set, the Email button is hidden, because it couldn't work without one.

## The private key

`.secrets/email-private-key.json` is generated by `node workers/contact/scripts/generate-keys.mjs` (run from the repo root) and is **git-ignored**. Keep a backup, for example in a password manager:

- **If it's lost**, every `emailEncrypted` value becomes unreadable. Generate a new pair with `--force`, then re-encrypt everyone's email.
- **If it leaks**, rotate it the same way.

## Local testing

Cloudflare publishes Turnstile test keys that always pass. Create `.dev.vars` (git-ignored):

```sh
TURNSTILE_SECRET=1x0000000000000000000000000000000AA
EMAIL_PRIVATE_KEY='<contents of .secrets/email-private-key.json>'
ALLOWED_ORIGINS=http://localhost:4321
ALLOWED_HOSTNAMES=
```

Then run the Worker and the site:

```sh
npx wrangler dev --port 8787
# in the repo root:
PUBLIC_CONTACT_API_URL=http://localhost:8787/reveal PUBLIC_TURNSTILE_SITE_KEY=1x00000000000000000000AA npm run dev
```
